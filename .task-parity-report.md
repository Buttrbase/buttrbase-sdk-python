## Shape/Naming Divergences Resolved (6)

| Divergence | Old (divergent) | New (canonical) | Backwards compat? |
|---|---|---|---|
| Entitlement check body field | `{"feature": ...}` | `{"feature_key": ...}` | ✅ Old `entitlements_check(feature, org_uuid?)` kept; new `check_entitlement(bearer, feature_key)` added |
| Entitlement batch body field | `{"checks": [...]}` | `{"feature_keys": [...]}` | ✅ Old `entitlements_check_batch(checks)` kept; new `check_entitlements(bearer, feature_keys)` added |
| Effective entitlements signature | `entitlements_effective()` (no bearer) | `effective_entitlements(bearer)` | ✅ Both exist; old kept |
| Usage report auth model | `usage_report(payload)` using bearer | `report_usage(event: UsageEvent)` using HTTP Basic | ✅ Old `usage_report` kept; new `report_usage` uses `client_id:client_secret` Basic auth, falls back to bearer if no creds set |
| Analytics event naming | `ingest_analytics_event(event)` (no bearer) | `ingest_event(bearer, event)` | ✅ Both exist; `ingest_event` is the canonical alias |
| Analytics overview period param | `analytics_app_overview(app_uuid)` (no period) | `analytics_app_overview(app_uuid, period=None)` | ✅ Fully backwards compat; `period=None` omits the param |
